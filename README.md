# Шлях донора

Інтерактивна гра українською мовою. Поточна версія містить 5 аркушів: знайомство, підготовка вдома, документи, дорога до станції та реєстратура.

## Завантаження

Завантажте весь вміст цієї папки до кореня вашого репозиторію, зберігши папку assets. Файл index.html має лежати в корені поруч з іншими HTML, CSS і JavaScript файлами.

Це статичний сайт для GitHub Pages. Встановлення залежностей, збірка й сервер Node.js для опублікованої гри не потрібні. Після публікації гра починається з index.html.

## Вміст

- index.html — перший аркуш;
- preparation.html — підготовка вдома;
- packing.html — збирання документів;
- journey.html — дорога до станції;
- registration.html — реєстрація обох героїв;
- assets/ — карти та персонажі;
- CSS і JS файли — оформлення та логіка гри.

Персональні дані в грі вигадані. Поточна гра завершується отриманням двох карток для терапевта. Наступні аркуші ще не входять до цієї версії.
